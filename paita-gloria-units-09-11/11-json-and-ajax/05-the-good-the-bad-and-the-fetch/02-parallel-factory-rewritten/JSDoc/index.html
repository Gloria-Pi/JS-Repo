main.js

This script loads data from a factory JSONBlob and multiple car JSONBlobs, processes the responses in parallel, and displays the content inside the DOM. It handles loading states, errors, and renders structured HTML lists for both the factory and car objects. For this exercise, the Fetch API is used instead of XMLHttpRequest for all HTTP requests.
