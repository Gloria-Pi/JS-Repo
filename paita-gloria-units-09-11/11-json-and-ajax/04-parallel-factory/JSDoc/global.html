carsGetRequest() → {void}

Sends parallel GET requests to all car endpoints in `carsEndpoints`, stores the parsed results into `carsArray`, and displays them in the DOM. Handles both network and JSON parsing errors individually for each car. Hides the loading message once all requests are successfully processed.
