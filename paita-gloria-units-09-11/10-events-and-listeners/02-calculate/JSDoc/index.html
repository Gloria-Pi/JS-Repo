This script is my approach to solving Exercise 02 of Unit 10. The goal of this exercise is to set up a dynamic calculator page that handles multiple types of calculations (to find the square of a number, half of a number, the percentage that one number is of another, the area of a circle with a given radius). The results will be displayed inside the "solution" div. As a personal bonus I created a reset button to clear the solution div and all input fields.
