addArrivalsStatus(arrivalsList, statusList) → {void}

Assigns an initial status to each flight. If the current time matches the flight's time, the status is set to `"ARRIVED"`. Otherwise, a random status is assigned from the provided list. If the status is `"DELAYED"`, an expected arrival time is calculated and added to the `notes` field.
Parameters:
Name Type Description
arrivalsList Array.<Object> Array of arriving flight objects.
statusList Array.<string> Array of possible flight statuses.
