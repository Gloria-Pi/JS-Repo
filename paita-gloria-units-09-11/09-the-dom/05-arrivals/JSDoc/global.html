addNextFlight(flight) → {void}

Creates a table row (`tr`) for a flight and appends it to the table body. If the flight is delayed, a special CSS class `"delayed"` is added for styling. Also stores the DOM row element in the `flight.rowElement` property for future access.
Parameters:

flight Object The flight object to render in the table.

Name Type Description

status string The flight status ("ON_TIME", "DELAYED", etc.).
notes string Any additional notes (e.g. "EXPECTED AT 14:45").

addStartingStatus(arrivalsList, statusList) → {void}

Assigns an initial status to each flight. If the current time matches the flight's time, the status is set to `"ARRIVED"`. Otherwise, a random status is assigned from the provided list. If the status is `"DELAYED"`, an expected arrival time is calculated and added to the `notes` field.

changeStatus(arrivalsList) → {void}

Updates the status of flights currently marked as `"DEPARTING"`. If a flight remains in this state for 6 intervals (60 seconds), it resets to `"ON_TIME"`. Also updates the flight's table row in the DOM. A `updateCounter` property is used to track how many intervals the flight has been in `"DEPARTING"`.

isArrived(arrivalsList) → {void}

Checks each flight to determine if it has arrived based on either: - `expectedDateObject` for delayed flights - `dateObject` for other statuses When a flight is considered arrived: - The status is updated to `"ARRIVED"` - The table is updated (status column and notes cleared) - The `"delayed"` class is removed from the row if present
