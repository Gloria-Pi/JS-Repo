oneToMany(num, noun) → {string}

This function takes a number and a singular noun as arguments. If the number is 0 or greater than 1, it returns the plural form of the noun; otherwise, it returns the singular form. The function includes predefined pluralization rules for common irregular nouns such as: - "cat" → "cats" - "sheep" → "sheep" (unchanged) - "goose" → "geese" If the noun is not in the predefined list, the function defaults to adding "s" to the singular form.
Parameters:
Name Type Description
num number The quantity associated with the noun (must be a positive number).
noun string A name in singular form to be turned into its plural form if necessary.

Examples
console.log(oneToMany(1, "cat")); 
// Logs: "1 cat"
console.log(oneToMany(3, "dog")); 
// Logs: "3 dogs"
console.log(oneToMany(4, "goose")); 
// Logs: "4 geese"
console.log(oneToMany(0, "bird")); 
// Logs: "0 birds"
