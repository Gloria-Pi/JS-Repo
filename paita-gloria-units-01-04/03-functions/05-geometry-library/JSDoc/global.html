calcArea(radius) → {void}

Calculates the area of a circle, given its radius. It also rounds the result to two decimal places, and logs the result to the console.
Parameters:
Name Type Description
radius number The radius of the circle.
Source:
  • main.js, line 40
Returns:
This function logs the result to the console and does not return anything.
Type
void
Examples
calcArea(3);                // Logs: "The area is 28.27."
calcArea(19);               // Logs: "The area is 1134.11."
calcArea(13.72);            // Logs: "The area is 591.37."
