tellFortune(jobTitle, location, partner, numChildren) → {void}

This function logs the fortune of a person to the console using a global variable, `fortune`. The variable is assigned the result of `console.log()`, which logs the personalized fortune message.
Parameters:
Name Type Description
jobTitle string The job title of the person.
location string The geographic location where the person will live.
partner string The name of the person's partner.
numChildren number The number of children the person will have.
Source:
  • main.js, line 13
Returns:
- This function logs the result to the console and does not return anything.
Type
void
Example
tellFortune("Dog Trainer", "Hawaii", "Brad Pitt", 1);
// Logs: "You will be a Dog Trainer in Hawaii, and married to Brad Pitt with 1 kids."
