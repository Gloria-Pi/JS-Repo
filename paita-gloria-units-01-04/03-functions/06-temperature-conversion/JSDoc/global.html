celsiusToFahrenheit(celsiusTemp) → {void}

Converts a temperature from Celsius to Fahrenheit and logs the result to the console. The result is rounded to one decimal place.
Parameters:
Name Type Description
celsiusTemp number The temperature in Celsius to be converted to Fahrenheit.
Source:
  • main.js, line 10
Returns:
This function logs the result to the console and does not return anything.
Type
void
Examples
celsiusToFahrenheit(0);         // Logs: "0°C is 32°F."
celsiusToFahrenheit(84.5);      // Logs: "84.5°C is 184.1°F."
celsiusToFahrenheit(-9);        // Logs: "-9°C is 15.8°F."
