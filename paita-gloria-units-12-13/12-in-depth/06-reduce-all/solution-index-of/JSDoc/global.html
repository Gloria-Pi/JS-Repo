myIndexOf(targetArray, searchElement, fromIndexopt) → {number}

Searches for the first occurrence of a given element in an array, starting from an optional index. Returns the index if found, or -1 if not found. This version uses `reduce` and mimics native behavior.
Parameters:
Name Type Attributes Default Description
targetArray Array The array to search in.
searchElement * The element to locate in the array.
fromIndex number <optional>
 0 The index to start searching from. Can be negative to count from the end.

Returns:
The index of the first matching element, or -1 if not found.
Type
number
Example
myIndexOf(["a", "b", "c"], "b");           // returns 1
myIndexOf(["a", "b", "c"], "d");           // returns -1
myIndexOf(["a", "b", "a"], "a", 1);        // returns 2
myIndexOf(["a", "b", "c"], "a", -2);       // returns -1
