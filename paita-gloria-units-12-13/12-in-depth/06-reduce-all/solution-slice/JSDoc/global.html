mySlice(targetArray, startopt, endopt) → {Array}

Returns a shallow copy of a portion of an array into a new array object. This custom implementation uses reduce() to reproduce the behavior of Array.prototype.slice().
Parameters:
Name Type Attributes Default Description
targetArray Array The array to slice.
start number <optional>
 0 The zero-based index at which to begin extraction. Negative values count from the end.
end number <optional>
 The zero-based index before which to end extraction. The element at this index is not included. Negative values count from the end.

Returns:
A new array containing the extracted elements.

Array
Example
mySlice(["a", "b", "c", "d"], 1, 3); // ["b", "c"]
mySlice(["a", "b", "c", "d"], -2);   // ["c", "d"]
mySlice(["a", "b", "c", "d"], 2, -1); // ["c"]
