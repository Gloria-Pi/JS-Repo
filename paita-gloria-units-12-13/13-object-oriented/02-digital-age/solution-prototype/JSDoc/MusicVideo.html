Class: MusicVideo

MusicVideo(configopt)

new MusicVideo(configopt)

Constructs a `MusicVideo` object, inheriting from `Video` and adding an `artist` property. If values are not valid, defaults are applied.
Parameters:
Name Type Attributes Default Description
config Object <optional>
 {} Optional configuration object.
Properties
Name Type Attributes Default Description
title string <optional>
 "Title" Title of the music video.
seconds number <optional>
 0 Duration of the video in seconds.
artist string <optional>
 "Artist" Name of the artist. Must be a string.

Methods

play()

Logs a message indicating the music video has been played. Includes the title and artist name in the message.
Source:
  • main.js, line 101
Example
const mv = new MusicVideo({ title: "River Flows in You", artist: "Yiruma" });
mv.play(); // You played "River Flows in You" by "Yiruma"
