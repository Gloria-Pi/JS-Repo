watch(nSecondsopt)

Logs how much of the video was watched. If a specific number is passed, it validates and displays it. Otherwise, assumes the entire video was watched.
Parameters:
Name Type Attributes Description
nSeconds number <optional>
 Optional number of seconds watched. Must be non-negative.

Example
const clip = new Video({ title: "Short Film", seconds: 90 });
clip.watch(); // You watched all 90 seconds of "Short Film"
clip.watch(45); // You watched 45 seconds of "Short Film"
